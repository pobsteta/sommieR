# Relecture d'un payload du registre 6

Rappelle le constructeur du type que le payload declare. Un payload sans
`type_entree` est une intervention : c'est le cas de toutes celles
inscrites avant la v0.28.0.

## Usage

``` r
registre6_depuis_payload(payload)
```

## Arguments

- payload:

  Payload relu (liste nommee).

## Value

Le payload revalide.
