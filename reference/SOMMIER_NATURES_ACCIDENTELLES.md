# Natures de phenomene qui laissent des produits accidentels

Une detection confirmee sur le terrain avec l'une de ces natures laisse
peut-etre des bois a exploiter hors martelage : des produits
accidentels, au registre 5 (voir
[`sommier_produit_accidentel()`](https://pobsteta.github.io/sommieR/reference/sommier_produit_accidentel.md)).
Une coupe confirmee comme exploitation ordinaire (`autre`) appelle,
elle, le martelage qui manque.

## Usage

``` r
SOMMIER_NATURES_ACCIDENTELLES
```

## Format

An object of class `character` of length 6.
