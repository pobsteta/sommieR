# Version de l'algorithme de chainage

Identifiant de l'algorithme d'empreinte, inclus dans les octets haches
afin que la chaine soit auto-descriptive : un verificateur lisant un
export sait quelle regle appliquer, et un changement d'algorithme ne
peut pas passer pour la meme chaine.

## Usage

``` r
SOMMIER_VERSION_CHAINE
```

## Format

An object of class `character` of length 1.
