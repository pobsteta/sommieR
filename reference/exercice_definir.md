# Fixation de la possibilite d'un exercice

Fixation de la possibilite d'un exercice

## Usage

``` r
exercice_definir(con, foret_id, annee, possibilite_m3_an)
```

## Arguments

- con:

  Connexion DBI.

- foret_id:

  UUID de la foret.

- annee:

  Annee de l'exercice.

- possibilite_m3_an:

  Possibilite annuelle en metres cubes.

## Value

Invisiblement, le nombre de lignes ecrites.
