# Etats d'un element de limite, selon sa forme

Une liste nommee : `point`, `ligne`, `surface`, `hors_plan`. Chacune
donne les etats qu'un constat peut porter pour un element de cette
forme, dans l'ordre ou le formulaire de terrain les propose. La forme
est celle de l'objet du plan, non sa categorie : un cours d'eau est une
ligne sur une feuille, une surface sur une autre. Voir
[SOMMIER_ETATS_LIMITE](https://pobsteta.github.io/sommieR/reference/SOMMIER_ETATS_LIMITE.md).

## Usage

``` r
SOMMIER_ETATS_PAR_FORME
```

## Format

An object of class `list` of length 4.
