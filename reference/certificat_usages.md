# Usages etendus declares par un certificat

Usages etendus declares par un certificat

## Usage

``` r
certificat_usages(certificat)
```

## Arguments

- certificat:

  Objet
  [`certificat_lire()`](https://pobsteta.github.io/sommieR/reference/certificat_lire.md).

## Value

Les OID de l'extension `extKeyUsage`, en notation pointee. Un vecteur
vide si l'extension est absente.
