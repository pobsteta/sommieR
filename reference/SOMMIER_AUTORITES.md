# Autorites de validation

Qui valide, selon le regime. C'est le seul point ou les trois regimes
divergent vraiment pour ce registre : arrete ministeriel ou prefectoral
et visa ONF en domanial, deliberations du conseil municipal en plus en
foret communale, agrement CRPF en prive.

## Usage

``` r
SOMMIER_AUTORITES
```

## Format

An object of class `character` of length 7.
