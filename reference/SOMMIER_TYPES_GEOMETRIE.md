# Types de geometrie admis dans un payload

Les trois types GeoJSON que le sommier accepte : un point, une ligne, un
polygone. Ni collection ni multi-partie — un constat porte sur un objet,
et regrouper plusieurs objets dans une entree ferait perdre a chacun sa
date et son auteur.

## Usage

``` r
SOMMIER_TYPES_GEOMETRIE
```
