# Nom de la foret du jeu de demonstration de Marsannay

Comme
[NOM_FORET_DEMO](https://pobsteta.github.io/sommieR/reference/NOM_FORET_DEMO.md),
le nom porte la mention « jeu de demonstration » pour qu'aucune lecture
de la base ne prenne ces ecritures pour reelles.

## Usage

``` r
NOM_FORET_DEMO_MARSANNAY
```
